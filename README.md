# ЛР11 — Мониторинг качества программного средства

## Используемые технологии
- Docker
- Docker Compose
- Django
- Prometheus
- Grafana

## Запуск проекта

```bash
docker compose up --build
```

## Сервисы

- Django: http://localhost:8001
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000
